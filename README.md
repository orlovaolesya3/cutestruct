# CuteStruct

Cсылочка ->  https://orlovaolesya3.github.io/cutestruct/   

**CuteStruct** — это пробный проект для милого размещения личного кода (поэтому стиль кода может не соответствовать общепринятым нормам).  
Проект содержит реализацию различных алгоритмов по олимпиадному программированию (примерно уровня C–B) на Python и C++, а также удобные интерактивные инструменты.

## Что есть на сайте

### Алгоритмы (код + теория)
- Графовые алгоритмы
- Поиск
- Динамическое программирование
- Вычислительная геометрия
- Структуры данных на деревьях
- Строки
- Теория чисел
- Комбинаторика

### Дополнительные страницы
- **База языков** — таблица с основными приёмами Python и C++, ссылки на официальную документацию
- **Информация** — список кружков, летних школ, перечень олимпиад по уровням, полезные ресурсы для подготовки
- **Визуализатор графов** — интерактивный инструмент для создания графов, перетаскивания вершин и визуализации BFS, DFS и Дейкстры
- **Графический редактор** — интерактивный инструмент для построения графиков, геометрических фигур и рисования

### Удобные дополнения
-  Переключение светлой и тёмной темы
-  Поиск по всем алгоритмам на главной странице
-  Кнопка для копирования кода
-  Можно смотреть с телефона (но лучше с компьютера)
-  У каждого алгоритма можно ввести свои данные и запустить пример
-  Милое оформление страниц

## Итог

На сайте собрано **более 80 алгоритмов** с кодом на **Python** и **C++**.  
Каждый алгоритм можно попробовать в **интерактивном режиме**.  
Сайт подойдёт для студентов, олимпиадников и всех, кто хочет разобраться в алгоритмах и структурах данных.
